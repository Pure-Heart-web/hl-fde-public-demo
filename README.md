# 猴来工作室 · 工业 AI 核验工作流 Demo

报价前，先把事实对齐。

本项目用人工设计的纯合成资料，展示「AI辅助核验 → 人工决策 → 证据留痕」的工作流。参数抽取、证据匹配、规则结论和来源失效均由前端预设逻辑模拟；不调用真实模型或业务后端，**不代表生产环境验收结果、客户验证或工程选型批准**。

## 体验内容

- A：两份资料均为85 m³/h，观察一致仍需人工核对完整性。
- B：询盘85、规格58 m³/h，BLOCKING_CONFLICT；人工状态不能放行冲突。
- C：模拟来源失效，清空可用候选、观察、发现、备注和草稿，停用相关操作。
- 查看完整合成引用，编辑人工记录和澄清草稿，在本页内存保存、复制或下载JSON。

所有交互在浏览器本地执行，无上传、账户、数据库、应用API或分析统计。请勿输入个人信息、真实客户资料或凭据。刷新或关闭页面会清除未导出的演示状态。导出的JSON和剪贴板内容由使用者在本机保管。

文件为普通HTML、CSS和原生JavaScript，不需要构建或安装依赖。index.html为入口，其他三个文件与其同目录；.nojekyll用于关闭默认Jekyll处理。使用现代浏览器。自动复制和下载受浏览器权限限制，复制失败时可在文本框内手动选择复制。

GitHub Pages只提供静态文件托管。本应用不采集个人信息，不等于托管方不处理访问数据；GitHub会为安全目的记录访客IP，详见[GitHub官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection)。
