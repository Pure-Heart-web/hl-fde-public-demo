# 猴来团队演练与走读打卡

本页是纯 HTML、CSS、原生 JavaScript 的独立静态练习，使用人工设计的 DS03 合成资料。

## 成员怎么用

1. 使用练习代号（不要填真实姓名），选择角色，开始练习。
2. 运行 DS03，展开两份合成来源，查看85/58阻断冲突。
3. 保存备注A、草稿A；编辑为B但不保存，导出已保存记录。
4. 文件应为A，页面继续B和未保存提示。明确保存B后再次导出才有B。
5. 回答5个角色问题及本人的理解总结，可填写改进建议。
6. 勾选本人声明，标记“自述打卡完成”。下载个人JSON记录，自己交给负责人。

“自述打卡完成”只记录本人在当前浏览器的陈述，不能证明身份、回答正确、独立完成或人员通过。人工验收始终为 NOT_EXECUTED，评分为 null，负责人另行验收。

## 实际执行与模拟

实际在浏览器执行：文本编辑、编辑版本/dirty记录、内存保存、简单引用展示、模拟结果状态切换、复制和JSON下载。

预置模拟：85/58候选、引用匹配标签、BLOCKING_CONFLICT、INPUT_INVALIDATED及撤销行为。本页没有运行Python、A3可信链或DeepSeek，不构成FIX-009后端验收证据、客户确认或工程批准。

保存只进入当前页面内存，刷新或关闭全部丢失。没有localStorage、sessionStorage、IndexedDB、上传、账号或共享数据库；不同页面不共享/同步记录，也没有集中打卡后台。本独立页的“复制当前文字”不会自动保存，与本地FIX-009工作台有所不同。

页面脚本不发起API请求，CSP的connect-src为none。浏览器加载GitHub Pages静态资源仍需网络；GitHub托管平台可能记录访问日志，这不等于本页收集成员答卷。

## JSON记录

- `HOULAI_STATIC_PRACTICE_SAVED_RECORD`：只包含当前模拟结果和本页已保存的备注/草稿；未保存文本不进入这份记录，只记是否存在未保存修改。
- `HOULAI_TEAM_PRACTICE_SELF_REPORT`：包含练习代号、角色、操作时间线、已保存内容、本人答卷/总结、当前完成状态与旧结果隔离文字。它是个人自述，不含身份认证。
- `evidence_class`固定为`STATIC_SIMULATION_NOT_FIX009_BACKEND_EVIDENCE`，`backend_verified`固定为false。
- `human_acceptance.status`为`NOT_EXECUTED`，分数/验收人为null；页面不自动评分或给出人员PASS。

个人记录可能包含本人输入的文字。仅填写合成练习信息，不要填客户资料、联系方式、API Key。文件由本人选择交给负责人，页面不会发送、汇总或通知其他人。

## 故障与重新体验

模拟来源失效会清空候选、observations、findings和当前草稿/备注，禁用相应编辑、保存和复制。未保存文字进入本页只读隔离区，不获得新结果授权。重新运行建立新的模拟结果，不复活旧结果。

重置核验保留走读答卷；若换成员，使用新的独立页面。自动复制失败会提示手动复制，不假称成功。下载失败时应保留本页并记录问题；不把文件不存在解释成已交回。

## 发布与维护

无构建、第三方依赖、模型凭据或后端。将本目录作为GitHub Pages中的`team-practice/`发布即可。测试、内部复审文件和本机路径不在发布目录。
